## Run locally

1. Extract the ZIP.
2. Open the extracted folder **containing `package.json`** in VS Code.
3. Run `npm install` and then `npm run dev`.
4. Open the local Vite URL (usually http://localhost:5173/).

You do **not** need WAMP. For Vercel: use Vite, build `npm run build`, output `dist`.
